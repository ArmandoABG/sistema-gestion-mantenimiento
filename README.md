SISTEMA DE GESTIÓN DE MANTENIMIENTO



SIGUE EN DESARROLLO



Sistema web desarrollado como parte de mis Residencias Profesionales, orientado a mejorar el registro, organización y seguimiento de los procesos de mantenimiento dentro de una empresa.



- Descripción



La plataforma permite centralizar información relacionada con equipos, solicitudes y trabajos de mantenimiento, facilitando el seguimiento de las actividades realizadas y el control de los diferentes estados del proceso.



El proyecto fue desarrollado a partir del análisis de necesidades reales de operación, buscando sustituir procesos dispersos por una solución web más organizada y fácil de consultar.



- Funcionalidades principales



* Registro y seguimiento de solicitudes de mantenimiento.

* Gestión de equipos.

* Asignación de personal técnico.

* Seguimiento de estados de los trabajos.

* Administración de información relacionada con mantenimientos.

* Consulta y organización de registros.

* Control de usuarios y permisos.

* Seguimiento del flujo de trabajo desde la solicitud hasta su conclusión.



- Tecnologías utilizadas

* CSS3
